# Copyied for Windows

For end users, download the `Copyied-Windows` artifact from GitHub Actions and double-click `Copyied.exe`. Python and a terminal window are not required.

To build it locally:

```powershell
..\build-windows.ps1
```

The Windows launcher files are kept in the project root for compatibility with the existing desktop shortcut.

Run from PowerShell:

```powershell
cd ..
.\run.ps1
```

To create the desktop shortcut:

```powershell
.\create-shortcut.ps1
```
